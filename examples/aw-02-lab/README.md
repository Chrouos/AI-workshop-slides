## 筆記庫裡有什麼

`三國人物知識庫/` 可直接作為 Obsidian 筆記庫開啟。根目錄放故事入口，人物、勢力、關係卡各放在同名資料夾。課堂把時間用在閱讀關係和練習整理，不必從空白開始抄卡。

```text
三國人物知識庫/
├── 三國演義.md
├── 人物/（5 張）
├── 勢力/（3 張）
├── 關係/（3 張）
├── 原文/（先放第 37、38、46 回節選；練習 2 再放進第一堂的第 1–21 回）
├── 模板/（關係卡模板.md：練習 2 寫自己的卡，第三堂新增卡片也用它）
└── 整理/（空的；練習做出的大綱、圖、時間軸、導覽頁都存這裡）
```

- 故事入口：〈三國演義〉。
- 人物卡：〈劉備〉、〈關羽〉、〈張飛〉、〈曹操〉、〈孫權〉。
- 勢力卡：〈蜀漢〉、〈曹魏〉、〈東吳〉。
- 關係卡：〈桃園結義〉、〈煮酒論英雄〉、〈赤壁之戰〉。

共 12 張卡。每張卡都用完整句子講故事，`[[連結]]` 直接寫在句子裡：讀〈關羽〉會順著讀到〈煮酒論英雄〉和〈赤壁之戰〉，不只是一串人名清單。卡裡提到、但還沒有卡的人物或事件（諸葛亮、周瑜、三顧茅廬、草船借箭）只寫純文字；第三堂會拿到照原文寫好的〈三英戰呂布〉〈白門樓〉〈草船借箭〉三張卡。`原文/` 一開始只有第 37、38、46 回的小說節選（三顧茅廬、草船借箭），練習時讀這幾回，不用上網。第 1–21 回在第一堂的 `aw-01-lab/Codex_練習/原文/`：練習 2 請學生把裡面的 21 個檔拖進同一個 `原文/`，和大綱一起放，第一堂大綱的「出處」才找得到。整門課的原文都在 `原文/` 一個資料夾，出處一律寫「原文/第0NN回.md」。原文都沒有勾 `dg-publish`，不算在 12 張卡裡，也不會被發布。三張關係卡的開頭有 `回目`（〈桃園結義〉另有 `年份：中平元年`），第三堂的時間軸 Skill 靠它排順序。`模板/關係卡模板.md` 是新增關係卡的格式，沒有 `dg-publish`。各堂練習的提示詞不放在筆記庫裡（放在裡面會被 Codex 搜到，也會跟著舊的 ZIP 過期），改放在每一堂的教材資料夾：[第二堂](prompts.md)、[第三堂](../aw-03-lab/prompts.md)、[第四堂](../aw-04-lab/prompts.md)。`整理/` 一開始是空的，練習做出的東西都存在這裡。三條可走的路線是「劉備 → 桃園結義 → 關羽／張飛」、「曹操 → 煮酒論英雄 → 劉備」、「孫權 → 赤壁之戰 → 曹操」。每條走三層，橫向有三條路；同一人物卡可被多條路線重用。資料夾用來分類，`[[連結]]` 用來跨資料夾探索；這裡的「三層」是閱讀深度，不是資料夾階層。
