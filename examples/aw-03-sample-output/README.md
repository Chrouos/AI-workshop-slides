# 第三堂練習的範例成品

上課照 [aw-03-lab/prompts.md](../aw-03-lab/prompts.md) 做，你的筆記庫裡會有自己的成品。這裡是範例，有兩種用法：

- 對照：想比較自己的結果時打開來看，不用放進筆記庫。
- 補上：第三堂沒做完，第四堂又需要這些檔案時（第四堂 prompts.md 練習 3-1），把 `練習3/時間軸.md` 放進筆記庫的 `整理/`，[aw-03-lab/關係/](../aw-03-lab/關係/) 的三張卡放進 `關係/`。拖檔案，不要拖整個資料夾。

- [練習2/](練習2/)：`三國關係圖.html` 是練習 2-1 用 diagram-design 2.6.136 畫的關係圖（2026-10-30），下載後用瀏覽器打開；`劉備-5歲版.md` 是練習 2-3 用 eli5 改寫給 5 歲小孩聽的劉備卡（2026-10-30）。
- [練習3/](練習3/)：`時間軸.md`、`時間軸-劉備.md` 是練習 3 補過規則後的結果；三份 `三國時間軸-*.html` 是練習 3-5 用 diagram-design、archify 畫的時間軸，和一份另外寫的自訂 HTML。
