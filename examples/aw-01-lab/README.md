# aw-01-lab：第一堂練習資料夾

這個資料夾給第一堂課用。你會在這裡打開 Codex，請它「只看資料夾裡的原文」寫出《三國演義》前 21 回的大綱。

## 裡面有什麼

- `原文/`：第 1 回到第 21 回的全文，一回一個檔案（`第001回.txt` … `第021回.txt`）。每個檔案第一行是回目，下面是正文。
- `回目.md`：21 回的回目清單，方便你快速查哪一回講什麼。
- `prompts.md`：練習要貼的提示詞，練習 1 貼給 ChatGPT，練習 2 貼給 Codex，照步驟做就好。

## 原文從哪裡來

原文取自維基文庫的《三國演義》，屬於公有領域，可以自由使用。

- 網址：https://zh.wikisource.org/wiki/三國演義/第001回
- 其他回把網址最後的 `001` 換成回數就好，例如第 21 回是 `第021回`。

整理時只拿掉了網頁上的導覽列和排版符號，文字內容沒有改。
