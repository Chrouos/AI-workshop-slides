# 第一堂練習 2-3 的範例成果

`三國演義大綱.md` 是講師用 `aw-01-lab/prompts.md` 練習 2-3 的提示詞，請 Codex（codex-cli 0.154.0）照 `原文/` 第 1–21 回寫出的大綱（2026-10-17 實跑）。

- 21 段，每段最後一行是出處，例如 `出處：原文/第001回.txt`。
- 內文的人名和已有卡片的事件寫成連結，例如 `[[劉備]]`、`[[桃園結義]]`；標題照回目原文，沒有連結。

用途：第一堂沒做完、或弄丟大綱的人，第二堂可以直接拿這份放進三國筆記庫的 `整理/`。你自己跑出來的版本，句子不會完全一樣。這是 AI 寫的大綱，內容請以 `原文/` 為準。
