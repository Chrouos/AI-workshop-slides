# 第三堂：三國時間軸 Skill 骨架

`sanguo-timeline/SKILL.md` 是第三堂練習 4 的起點。

## 放哪裡

把整個 `sanguo-timeline` 資料夾複製到三國筆記庫裡的 `.agents/skills/`：

```text
三國人物知識庫/
└── .agents/
    └── skills/
        └── sanguo-timeline/
            └── SKILL.md
```

`.agents` 開頭是點，Finder／檔案總管預設會藏起來：Mac 按 `Cmd + Shift + .`，Windows 在檔案總管勾「顯示 → 隱藏的項目」。放好後重開 Codex，輸入「請使用 sanguo-timeline skill，排出三國時間軸」。

## 講師實測（2026-10-17，Codex 0.154.0）

照這份骨架跑，會排出 6 件事（第 1、5、19、21、46、49 回），但有兩個地方不理想：

1. 年份欄寫成「未標註」，不是留空。
2. 「來源卡」做成連到 `../關係/*.md` 的連結，發布到網站後會 404。

在「輸出格式」加兩行就能修好，這正是課堂上要練的「改 SKILL.md，再跑一次」：

```text
- 年份照卡片抄，卡片沒寫就留空白，不要寫「未標註」
- 來源卡只寫檔名純文字，不做連結
```

時間軸筆記產生時沒有 frontmatter，第四堂要發布前，記得在最上面加上 `dg-publish: true`。

## 進階：只排某個人的事件

在「步驟」加第 4 步：

```text
4. 使用者指定人物時，只留下參與人物有他的事件
```

重開 Codex 後輸入「請使用 sanguo-timeline skill，只排劉備的事件，存成 整理/時間軸-劉備.md」。講師實測（2026-10-18）：排出 5 件，草船借箭因為參與人物沒有劉備，被正確拿掉。
