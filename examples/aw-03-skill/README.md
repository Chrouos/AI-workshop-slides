# 第三堂：三國時間軸 Skill 骨架

`sanguo-timeline/SKILL.md` 是第三堂練習 4 的起點。

## 放哪裡

Skill 要放在三國筆記庫裡的 `.agents/skills/`：

```text
三國人物知識庫/
└── .agents/
    └── skills/
        └── sanguo-timeline/
            └── SKILL.md
```

`.agents` 開頭是點，是隱藏資料夾：Mac 的 Finder 不讓你建點開頭的資料夾，Obsidian 也看不到它。所以課堂上不自己複製，而是請 Codex 建檔。提示詞在 [../aw-03-lab/prompts.md](../aw-03-lab/prompts.md) 的「練習 4-1」，裡面已經附上這份骨架的全文。

建好後在 Codex 輸入 `/quit`，再打 `codex` 重開，輸入「請使用 sanguo-timeline skill，排出三國時間軸。」Codex 要開在「三國人物知識庫」這個資料夾，才找得到這個 Skill。

## 講師實測（Codex 0.154.0）

照這份骨架跑，會排出 6 件事（第 1、5、19、21、46、49 回），但骨架沒寫清楚兩件事，每次跑出來的毛病不一樣：

- 2026-10-17：年份欄寫「未標註」；來源卡做成連到 `../關係/*.md` 的 `<a href>`，發布到網站後會 404。
- 2026-10-24：年份欄寫「—」；來源卡寫成 `[[關係/桃園結義]]` 這樣的連結。

在「輸出格式」加兩行，兩次的毛病都修好了，這正是課堂上要練的「說明書沒寫清楚，就補一條規則」：

```text
- 年份照卡片抄，卡片沒寫就留空白，不要寫「未標註」或「—」
- 來源卡只寫檔名純文字，不做連結，不用 <a href>，也不用 [[ ]]
```

時間軸筆記產生時沒有 frontmatter，第四堂要發布前，記得在最上面加上 `dg-publish: true`。

## 進階：只排某個人的事件

在「步驟」加第 4 步：

```text
4. 使用者指定人物時，只留下參與人物有他的事件
```

重開 Codex 後輸入「請使用 sanguo-timeline skill，只排劉備的事件，存成 整理/時間軸-劉備.md」。講師實測（2026-10-18、2026-10-24 各一次）：排出 5 件，草船借箭因為參與人物沒有劉備，被拿掉。

修好的版本放在 [../aw-03-lab/範例/sanguo-timeline-修好版/SKILL.md](../aw-03-lab/範例/sanguo-timeline-修好版/SKILL.md)。
