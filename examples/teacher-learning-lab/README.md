# 教師 AI 學習練習場

這是一個不需要寫程式的練習專案。請把它當成自己的小型學習工作區，讓 Agent 協助你閱讀、整理、提問與產出教材。

## 資料夾結構

```text
teacher-learning-lab/
├── README.md
├── notes/
│   └── example-ai-learning.md
└── templates/
    └── learning-note.md
```

- `notes/`：放自己的學習筆記或課程主題
- `templates/`：放固定格式，讓每次新增筆記都有一致結構
- `README.md`：告訴 Agent 這個練習場的用途與規則

## 使用規則

1. 第一次先請 Agent 閱讀，不要立刻修改檔案。
2. 要新增或改寫內容時，先請 Agent 提出草稿，再由自己確認。
3. 不要放入學生個資、成績、帳號密碼或未公開資料。
4. AI 產生的內容要標記哪些是自己的想法、哪些需要查證。

## 建議練習順序

1. 請 Agent 說明這個專案的用途與檔案結構。
2. 使用 `templates/learning-note.md` 新增一篇自己的學習筆記。
3. 請 Agent 把筆記整理成一個 15 分鐘的教學活動。
4. 請 Agent 反問你 3 個問題，找出理解上的空白。
5. 請 Agent 列出內容中需要查證的地方，不要直接相信所有答案。
