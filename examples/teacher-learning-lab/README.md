# 三國故事：Agent 讀筆記與畫圖練習

從劉備、關羽、張飛與桃園結義開始，再加入曹操和煮酒論英雄。不用先熟悉三國史，也不需要寫程式。

目標是讓 Agent 讀取六份短筆記、列出人物與事件的關係，回原文核對後，再做可查證的關係圖；故事時間線是加分選做。教材描述的是《三國演義》小說情節。

## 資料夾

```text
teacher-learning-lab/
├── README.md
├── prompts.md
├── prework.md
├── notes/
│   ├── README.md
│   ├── 劉備.md
│   ├── 關羽.md
│   ├── 張飛.md
│   ├── 曹操.md
│   ├── 桃園結義.md
│   └── 煮酒論英雄.md
├── templates/knowledge-note.md
├── outputs/README.md
└── diagrams/README.md
```

- `notes/`：四張人物卡、兩張事件卡；保留原文，讓每個結果都能回來核對。
- `prompts.md`：與投影片一致的提示詞，可直接複製。
- `outputs/`：核對後的純文字草稿。
- `diagrams/`：最後產生的單檔 HTML，關係圖必做，時間軸加分。
- `templates/knowledge-note.md`：之後新增人物或事件的筆記模板。

## 練習順序

1. **讀六份筆記**：列出筆記名稱、相關人物、關係說明與依據句子，先不改檔。
2. **精讀煮酒論英雄**：用教學草稿練習，請 AI 每一行附上原句，刪掉找不到原句的那行，再存成 `outputs/煮酒論英雄-草稿.md`。
3. **畫成知識圖**：重新讀取六份筆記及已核對草稿；產生 `diagrams/三國故事.html`。

先完成關係圖並核對每條線，再視進度選做時間軸。

關係圖回答「誰參與哪件事」；時間軸回答「哪件事先出現」。時間軸按小說回目排序，不把回目當歷史年份。

課前安裝、登入與備用方式見 [prework.md](prework.md)；課堂提示詞見 [prompts.md](prompts.md)。使用 ChatGPT 網頁版的人，先上傳相同筆記，再複製提示詞；成果需自行下載或存檔。

## 完成檢查

- 四位人物、兩個事件有沒有列齊？
- 有沒有因為劉備與曹操同場對話，就推論兩人是盟友？
- 有沒有畫出筆記裡找不到原句的線？
- 曹操有沒有被錯接到桃園結義？
- 同一個劉備有沒有接上兩段故事？
- 每條線都能指到筆記中的依據句子嗎？
- 若完成加分時間軸，是否先第 1 回，再第 21 回？
- `notes/` 是否保持原樣，草稿與 HTML 是否存對資料夾？

## 接到第二篇 Obsidian 課程

第二篇使用 [三國人物知識庫](../obsidian-agent-knowledge-garden/三國人物知識庫)，把相同六個主題擴展為 12 張知識卡，加入孫權、赤壁及勢力。先學會核對一條線，再學卡片如何互連、擴充與發布。

## 60 分鐘課堂安排

| 時間 | 內容 |
| --- | --- |
| 0–8 分 | 故事、成果、找錯、必要操作 |
| 8–20 分 | 練習 1：讀六份筆記，列關係與依據 |
| 20–35 分 | 練習 2：純文字草稿、回原文核對、存檔 |
| 35–55 分 | 練習 3：關係圖必做、逐線查證；時間軸加分 |
| 55–60 分 | 換成自己的教材，分享查證方法 |

安裝與登入請於課前完成；教材圖表是文學情節的整理，不是歷史事實認證。
