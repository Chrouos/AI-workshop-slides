# 課堂 Prompt 一覽｜三國故事

照上課順序複製到 Codex。四張人物卡：劉備、關羽、張飛、曹操；兩張事件卡：桃園結義、煮酒論英雄。六份筆記不含 README。

使用 ChatGPT 網頁版（Plan B）：先上傳要用的筆記，再貼同一段提示詞。需要寫入檔案時，請下載成果或自行複製存檔。

課前安裝與環境確認見 [prework.md](prework.md)。課堂主線不重做安裝。所有練習只用已授權使用的教材。

## 單篇示範｜範圍說清楚的 B

先用一份筆記看提示詞怎麼寫；正式練習 1 再擴大讀六份。

```text
只讀 notes/桃園結義.md。
列出 3 位人物、1 種關係，附支持的句子。
先不要改檔案，也不要加入原筆記沒有的事實。
```

## 練習 1｜讀六份筆記，先列關係表

```text
請閱讀 notes/ 裡的六份故事筆記（不含 README），整理成一張表：
- 筆記名稱
- 人物或事件
- 相關人物
- 關係說明
- 依據句子
- 來源回目

不要自行補入筆記沒有的故事或史實。
先不要修改任何檔案。
```

看完表，挑一列追問：

```text
為什麼兩件事都有劉備？請列出筆記裡支持的句子。
```

## 練習 2｜精讀煮酒論英雄，核對推論

### 第 1 步：出草稿，先不要存

```text
請只讀 notes/煮酒論英雄.md，用 ASCII（純文字）排出：
- 事件
- 參與人物
- 人物關係
- 來源回目

不要加入原筆記沒有的事實。
先把草稿顯示在畫面上，不要存檔。
```

### 第 2 步：回原文核對

```text
請對照 notes/煮酒論英雄.md，把草稿裡每一條關係，各自列出原文哪一句支持它；找不到就寫「找不到」。
先不要修改任何檔案。
```

一起談論英雄，不足以證明兩人是政治上的盟友。投影片的「兩人是盟友」是刻意加入的未證實推論，不代表 Agent 一定會產生同樣的回答。

核對有三種結果：原文支持就保留；原文不足就標「待確認」；與原文明確不符才修正或刪除。沒有證據不等於已證明相反。

### 第 3 步：改好才存檔

```text
請把與原文相反的關係修正或刪掉。
找不到支持的內容標「待確認」，不要當成已確認的關係。
再把修正後的草稿寫入 outputs/煮酒論英雄-ascii.md。
不要修改 notes/ 的來源筆記。
```

## 練習 3｜必做 Graph，Timeline 加分

diagram-design 於課前安裝。若沒有這個 Skill，移除下方「使用 diagram-design」，沿用其餘要求產生 HTML 即可。

```text
請使用 diagram-design，讀取 notes/ 的六份故事筆記，以及已核對的 outputs/煮酒論英雄-ascii.md。

請先做一張給初學者看的 Graph（關係圖）：
- 四位人物、兩個事件。人物用圓形，事件用方框。
- 劉備只畫一次，接上桃園結義與煮酒論英雄。
- 每條線標示關係，附筆記檔名及依據句子。
先只做 Graph，不加入 Timeline。

只把有來源支持的關係畫成實線。待確認主張另列，不混入已確認的連線。
不要加入筆記沒有的關係。
先說明圖的設計，等我確認後，再存成 diagrams/三國故事.html。
使用單檔 HTML，內嵌 CSS 與 SVG，不載入外部套件。
來源連結指向 ../notes/ 裡的筆記；不要修改來源檔。
```

### 開圖後，再核對一次

```text
請檢查 diagrams/三國故事.html：
- 桃園結義只接劉備、關羽、張飛，沒有誤接曹操嗎？
- 煮酒論英雄有接到曹操與劉備嗎？
- 有沒有把「兩人談論英雄」擅自改成「兩人是盟友」？
- 待確認的主張是否另列，沒有畫成已確認的實線？
- 劉備有沒有只出現一次，並接上兩件事？
- 每條線是否都有 notes/ 的來源支持？
先列出問題與依據，不要直接修改檔案。
```

### 加分選做｜Graph 核對完成後再加 Timeline

尚未完成的人繼續核對 Graph。Timeline 不列入必做成果。

```text
保留已核對的 Graph 及其來源，在同一份 diagrams/三國故事.html 加入 Timeline。
依小說回目排事件：第 1 回桃園結義在前，第 21 回煮酒論英雄在後。
回目不是歷史年份，註明間距不代表經過時間。
每件事附來源筆記與回目，不加入筆記沒有的日期。
先說明將修改哪些部分，確認後再寫入。
```

完成後確認事件先後與來源，且原有 Graph 沒有遺失。
