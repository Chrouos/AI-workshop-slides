# 圖表輸出區

練習三使用六份故事筆記和核對過的 ASCII 草稿，產生 `三國故事.html`，確認 Agent 已完成寫入後，再開啟圖檔。

必做成果：

- Graph：四位人物、兩個事件。劉備只出現一次，同時接到桃園結義與煮酒論英雄。
- 來源：每條關係附筆記檔名與依據，能連回 `../notes/` 中的檔案。

請 Agent 用單檔 HTML、內嵌 CSS 與 SVG，不載入外部套件。圖要先提設計，確認後再產生。

## 加分選做

Graph 每條線都核對完成，再於同一份 HTML 加入 Timeline，依小說回目排第 1 回、第 21 回。回目不是歷史年份；間距不代表時間長度。尚未完成 Graph 的人先繼續查證，不必加時間線。

### 開啟成果與來源

1. 先確認 Agent 已完成寫入，請它列出 `diagrams/三國故事.html` 的完整路徑；只有對話中的程式碼還不算存好
2. 在 Finder（macOS）或檔案總管（Windows）進入 `teacher-learning-lab/diagrams`，把 `三國故事.html` 拖進瀏覽器
3. 用文字編輯器打開 `notes/` 對應的 `.md` 筆記，對照來源原句；若瀏覽器點來源後只下載檔案，直接開原本的本機筆記核對

這是本機 HTML，不需要啟動伺服器或另外開 PORT。使用 ChatGPT 備用方式時，先下載 HTML 到 `diagrams/` 再開啟。
