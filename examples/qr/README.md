# QR code 總表

投影或印出來給學生掃。每張都已解碼核對過，掃了會直接打開下面寫的網址；標「ZIP」的會直接下載。

簡報投影片上已經有每堂的提示詞 QR（第一堂另有練習資料夾 ZIP、第二堂另有筆記庫 ZIP），這裡是全部集中的版本，含簡報上沒有的第三堂範例和第三堂完成版。
