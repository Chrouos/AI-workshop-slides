# 第三堂：Skills

整包下載：[aw-03-lab.zip](https://raw.githubusercontent.com/Chrouos/AI-workshop-slides/main/examples/aw-03-lab.zip)。Codex 一樣開在你自己的「三國人物知識庫」，這個資料夾只是教材，不用在這裡打開 Codex。

```text
aw-03-lab/
├── prompts.md          三個練習的步驟和提示詞
├── sanguo-timeline/    練習 3 的時間軸 Skill 骨架（練習 3-1 用 npx skills add 裝）
└── 關係/               三張照原文寫好的關係卡（練習 3-1 第一步拖進筆記庫的 關係/）
```

- [prompts.md](prompts.md)：請在筆電打開，整段複製，不用照投影片打字。
- [sanguo-timeline/](sanguo-timeline/SKILL.md)：時間軸 Skill 的原始骨架。練習 3-1 在筆記庫的終端機打 `npx skills add`，把這個資料夾拖進去，就會裝成筆記庫的 `.agents/skills/sanguo-timeline/`。eli5、diagram-design 這些別人寫的 Skill 不放在這裡，照 prompts.md 練習 1 用 `npx skills add` 從 GitHub 裝。
- [關係/](關係/)：三英戰呂布、白門樓、草船借箭三張關係卡，照原文（第 5、19、46 回）寫的，回目、年份、出處都填好了。時間軸要有事件可以排，練習 3-1 第一步把這三個檔案拖進筆記庫的 `關係/`。
- 每個練習的範例成品（關係圖、eli5 改寫、時間軸）放在線上：[aw-03-sample-output/](../aw-03-sample-output/README.md)，想對照自己的結果再打開。
