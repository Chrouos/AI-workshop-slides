# 第三堂：Skills

整包下載：[aw-03-lab.zip](https://raw.githubusercontent.com/Chrouos/AI-workshop-slides/main/examples/aw-03-lab.zip)。Codex 一樣開在你自己的「三國人物知識庫」，這個資料夾只是教材，不用在這裡打開 Codex。

```text
aw-03-lab/
├── prompts.md               四個練習的步驟和提示詞
├── eli5/                    git 裝不起來時的備用 Skill
├── sanguo-timeline-骨架/     練習 4 的時間軸 Skill 起點
└── 參考結果/                 講師 2026-10-24 實跑的成品，卡住時才用
    ├── 圖/三國關係圖.html            練習 2-1（diagram-design 2.6.115）
    ├── 整理/劉備-國中生版.md          練習 2-3（eli5）
    ├── 關係/三英戰呂布.md、白門樓.md、草船借箭.md   練習 3-1
    ├── 整理/時間軸.md                練習 4-3 補過兩條規則後
    ├── 整理/時間軸-劉備.md            練習 4-4
    └── sanguo-timeline-修好版/SKILL.md  加過兩條規則和第 4 步
```

- [prompts.md](prompts.md)：請在筆電打開，整段複製，不用照投影片打字。
- [eli5/](eli5/)：eli5 的 SKILL.md 備份，裝法寫在 prompts.md 最後的「備用做法」。eli5 的作者是 DreambigOu，MIT 授權，原始碼在 https://github.com/dreambigou/eli5 ，授權全文在 [eli5/LICENSE](eli5/LICENSE)。
- [sanguo-timeline-骨架/](sanguo-timeline-骨架/README.md)：時間軸 Skill 的原始骨架。prompts.md 的練習 4-1 已經附上全文，請 Codex 建檔就好。
- [參考結果/](參考結果/)：練習卡住、Codex 沒跑出來時才用。

放進筆記庫時，拖「檔案」到同名資料夾裡，不要拖整個資料夾：Mac 的 Finder 會問要不要「取代」，按下去會把筆記庫裡原本的資料夾整個換掉。

第二堂缺課、沒有筆記庫的人：下載第二堂的 [aw-02-lab.zip](https://raw.githubusercontent.com/Chrouos/AI-workshop-slides/main/examples/aw-02-lab.zip)，用 Obsidian 打開裡面的「三國人物知識庫」。
