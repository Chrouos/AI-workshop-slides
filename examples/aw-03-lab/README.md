# 第三堂：Skills

- [prompts.md](prompts.md)：四個練習的步驟和提示詞。請在筆電打開，整段複製，不用照投影片打字。
- [eli5/](eli5/)：eli5 的 SKILL.md 備份，給 git 裝不起來的人用，裝法寫在 prompts.md 最後的「備用做法」。eli5 的作者是 DreambigOu，MIT 授權，原始碼在 https://github.com/dreambigou/eli5 ，授權全文在 [eli5/LICENSE](eli5/LICENSE)。
- [範例/](範例/)：講師 2026-10-24 照 prompts.md 實跑的成品。練習卡住、Codex 沒跑出來時才用。整包下載：[第三堂範例.zip](https://raw.githubusercontent.com/Chrouos/AI-workshop-slides/main/examples/aw-03-lab/%E7%AC%AC%E4%B8%89%E5%A0%82%E7%AF%84%E4%BE%8B.zip)，解壓縮後是一個「第三堂範例」資料夾，裡面的東西和下面一樣。

```text
範例/
├── 圖/三國關係圖.html            練習 2-1（diagram-design 2.6.115）
├── 整理/劉備-國中生版.md          練習 2-3（eli5）
├── 關係/三英戰呂布.md、白門樓.md、草船借箭.md   練習 3-1
├── 整理/時間軸.md                練習 4-3 補過兩條規則後
├── 整理/時間軸-劉備.md            練習 4-4
└── sanguo-timeline-修好版/SKILL.md  加過兩條規則和第 4 步
```

放進筆記庫時，拖「檔案」到同名資料夾裡，不要拖整個資料夾：Mac 的 Finder 會問要不要「取代」，按下去會把筆記庫裡原本的資料夾整個換掉。
