# 三國時間軸

## 步驟
1. 讀 關係/ 每張卡的 回目、年份、參與人物
2. 依回目由小到大排；沒有回目的卡，最後列出來
3. 寫入 整理/時間軸.md
4. 使用者指定人物時，只留下參與人物有他的事件

## 輸出格式
- 一段 HTML，每件事一列：回目、年份、事件、人物
- HTML 裡的人名用純文字，不加 [[ ]]
- 表格下方列出每一列的來源卡。
- 年份照卡片抄，卡片沒寫就留空白，不要寫「未標註」或「—」
- 來源卡只寫檔名純文字，不做連結，不用 <a href>，也不用 [[ ]]
