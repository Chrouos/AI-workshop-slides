# 《三國演義》人物知識卡範例

`三國人物知識庫/` 可直接作為 Obsidian 筆記庫開啟；也可先下載[整盒筆記 ZIP](三國人物知識庫.zip)並解壓縮。根目錄放故事入口，人物、勢力、關係卡各放在同名資料夾。課堂把時間用在閱讀關係和練習整理，不必從空白開始抄卡。

```text
三國人物知識庫/
├── 三國演義.md
├── 人物/（5 張）
├── 勢力/（3 張）
└── 關係/（3 張）
```

- 故事入口：〈三國演義〉。
- 人物卡：〈劉備〉、〈關羽〉、〈張飛〉、〈曹操〉、〈孫權〉。
- 勢力卡：〈蜀漢〉、〈曹魏〉、〈東吳〉。
- 關係卡：〈桃園結義〉、〈煮酒論英雄〉、〈赤壁之戰〉。

共 12 張卡。三條可走的路線是「劉備 → 桃園結義 → 關羽／張飛」、「曹操 → 煮酒論英雄 → 劉備」、「孫權 → 赤壁之戰 → 曹操」。每條走三層，橫向有三條路；同一人物卡可被多條路線重用。資料夾用來分類，`[[連結]]` 用來跨資料夾探索；這裡的「三層」是閱讀深度，不是資料夾階層。

內容取自小說《三國演義》，不等同歷史考證。情節可回[第 1 回](https://zh.wikisource.org/wiki/三國演義/第001回)、[第 21 回](https://zh.wikisource.org/wiki/三國演義/第021回)、[第 43 回](https://zh.wikisource.org/wiki/三國演義/第043回)、[第 49 回](https://zh.wikisource.org/wiki/三國演義/第049回)、[第 50 回](https://zh.wikisource.org/wiki/三國演義/第050回)核對；曹丕與劉備稱帝見[第 80 回](https://zh.wikisource.org/wiki/三國演義/第080回)。

投影片示範如何開啟這份筆記庫，並從三張關係卡探索人物。12 張範例卡已預設 `dg-publish: true`；入口卡另外設有 `dg-home: true`。這些只是公開小說範例，發布前仍請檢查內容與公開範圍。內部連結不會自動讓目標頁公開。
