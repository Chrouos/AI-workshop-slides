# 練習提示詞

投影片上只放重點，完整提示詞在這裡。在 Obsidian 打開這一頁，選取一整段（灰色框裡的文字）複製，到 Codex 一次貼上，最後再按 Enter。不要一行一行打：在 Codex 裡每按一次 Enter，就會把目前打的字先送出去。

這一頁沒有勾 dg-publish，不會被發布。

## 查筆記練習

```text
請在這個筆記庫找〈曹操〉。
根據筆記，曹操參與了哪場戰役？
請核對相關的關係卡，回答並附上檔名。
找不到根據的細節不要補寫。
```

## 練習一：畫現有的知識圖

```text
請讀取〈三國演義〉和 人物/、勢力/、關係/ 裡的卡，共 12 張，不要修改原檔。
用純文字畫「人物 → 關係卡 → 人物」的關係圖，放在程式碼區塊裡。
只用筆記裡的 [[連結]] 作線；不要猜不存在的線。
圖下方、程式碼區塊外面，另外列一份連結清單，每條線一行，例如：[[劉備]] — [[桃園結義]] — [[關羽]]（來源：關係/桃園結義.md）。
最後列出筆記提到、但還沒有卡的人物或事件。
存成 整理/人物關係圖－擴充前.md；檔案開頭不要加 dg-publish。
```

## 練習二：請 Agent 增加 4 張卡

```text
保留原本 12 張卡，不覆寫；寫入前先給我看差異。
事實只取自 原文/ 資料夾裡的三份節選，不要上網。
新增 人物/諸葛亮、人物/周瑜、關係/三顧茅廬、關係/草船借箭，共 4 張卡，每張附回目和節選檔名。
寫法比照現有的卡：用完整句子交代來龍去脈，把 [[連結]] 寫進句子裡。
可以讀舊卡，把新卡接到已有的劉備、關羽、張飛、曹操等卡；節選沒寫到的關係一律標「待確認」，不要自行補線。
新卡開頭不要加 dg-publish。
```

## 練習三：重畫圖，加上時間線

```text
用練習一的規則，重畫全部人物卡與關係卡（含剛加的 4 張）的純文字關係圖，圖下方同樣附連結清單，
存成 整理/人物關係圖－擴充後.md。
另做 整理/故事時間線.md：依小說回目排關係卡，每件事連回它的 [[關係卡]] 並標回目。
回目是小說的順序，不要寫成歷史年份。兩個新檔開頭都不要加 dg-publish。
最後比較前後兩張圖：新增了哪些卡、哪些線、哪些可以走的路？
```

## 導覽頁練習：替知識庫做首頁

```text
新增 整理/知識庫導覽.md，不要改寫來源卡。
用 [[連結]] 放入擴充後關係圖與故事時間線。
列出「從人物看關係」與「按故事順序看」兩條路，各選一個例子，連回人物卡、關係卡和回目。
還沒核對的卡標「待確認」；檔案開頭不要加 dg-publish；寫入前先給我看差異。
```

做完後，自己動手：打開〈三國演義〉，在最後一行打 `[[知識庫導覽]]`。網站首頁是〈三國演義〉，少了這行，讀者在網站上走不到導覽頁。

## 完整練習：請 Agent 解釋新卡

```text
請說明〈三顧茅廬〉和〈草船借箭〉兩張卡：每一句根據的是 原文/ 哪一份節選的哪一段？
找不到根據的句子請標出來，不要修改檔案。
```

## 加分（課後）：做成一個網頁

```text
把 整理/人物關係圖－擴充後.md 和 整理/故事時間線.md 做成單一 HTML 檔，同一頁顯示關係圖和時間線。
不要載入外部套件；每個節點都連回來源筆記。
```
