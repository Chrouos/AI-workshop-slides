2. 點大綱第 1 回的劉備，要跳到 人物/劉備.md。

## 練習 2（連結）：寫一張關係卡

定位：大綱挑一回｜期望輸出：句子裡放 `[[ ]]`｜限制：原文沒寫不寫

1. 在「關係/」按右鍵選「新增筆記」，取名就是事件名稱。
2. 用完整的句子寫，人名前後加 `[[ ]]`，至少連到兩位人物。
3. 最後一行寫出處，例如「出處：原文/第005回.txt」。

可以挑的事件：第 5 回溫酒斬華雄、第 8 回連環計、第 16 回轅門射戟。三英戰呂布和白門樓先不要寫，第三堂會請 Codex 做這兩張，同名會撞在一起。不確定細節就打開 原文/ 裡那一回找。

看結果：打開自己的卡，右邊的反向連結和關聯圖多了一條線。

## 練習 3（RAG）：先核對這份回答

## 練習 3（RAG）：問一題，核對三件事

1. 打開終端機（Windows 是 PowerShell），打 cd 和一個空格，把「三國人物知識庫」資料夾拖進視窗，按 Enter。
2. 打 codex，再輸入 /status，Directory 那一行的結尾要是「三國人物知識庫」。
3. 把下面第一行換成你的問題，整段貼上。

定位：只查筆記庫｜期望輸出：答案＋檔名｜限制：沒寫就說找不到

```text
（你的問題）？
請只根據這個筆記庫裡的 .md 卡片回答，
每個說法後面附上檔名；
筆記沒寫的就說找不到，不要自己補。
```

想不到題目，可以用：誰在轅門射戟？關羽斬了誰？在第幾回？劉備怎麼離開許都？

看結果：先看 Codex 讀了哪些檔，再打勾三件事：檔案在嗎、原句在嗎、有沒有多寫。

# 第四堂：發布成網站

## 練習 1（部署）：建立自己的網站

定位：官方模板｜期望輸出：一個網址｜限制：卡 5 分鐘就舉手

1. 先在瀏覽器登入 GitHub 和 Vercel。
2. 打開 Digital Garden 官方入門頁，按 Deploy to Vercel：https://docs.forestry.md/getting-started/01-getting-started/
3. Repository Name 填 my-garden，按 Create。名稱重複就改成 my-garden-2。
4. 等部署完成，打開網址。

看結果：看到 Digital Garden 模板的首頁，repo 名稱和網址抄下來。

## 練習 2（token）：連上 GitHub

定位：今天的儲存庫｜期望輸出：三格都填好｜限制：token 不外流

1. 在三國人物知識庫裡裝外掛：設定 →「第三方外掛程式」→ 社群外掛程式按「瀏覽」→ 搜尋 Digital Garden → 安裝 → 啟用。
2. 打開 https://github.com/settings/personal-access-tokens/new 建 fine-grained token：名字取 digital-garden、期限 90 天、Repository access 選 Only select repositories 只勾 my-garden、Permissions 把 Contents 和 Pull requests 改成 Read and write，按 Generate token 後馬上複製。
3. 設定 → Digital Garden，填三格：GitHub repo name 只填 my-garden，GitHub Username 填 github.com/ 後面那段，GitHub token 貼剛才複製的那串。

看結果：三格都有值；token 只放在外掛裡，不貼進筆記、截圖或群組。

## 練習 3（dg-publish）：發布時間軸卡

定位：時間軸＋導覽頁｜期望輸出：首頁點得到｜限制：先查開頭三行

1. 第三堂新增的卡一張一張打開，查開頭三行。〈劉備-國中生版〉如果有 dg-publish，又不想公開，就刪掉那行。
2. 整理/時間軸.md 開頭沒有屬性，要公開就在最上面加這三行：

```text
---
dg-publish: true
---
```

3. 做導覽頁，可以手打，也可以請 Codex 做：

```text
請在 整理/ 新增〈知識庫導覽〉。分成人物、事件、時間三段，每段用 [[連結]] 列出筆記庫裡已經有的卡；只連到已有的卡，不要新增卡片。開頭加上 dg-publish: true。寫入前先給我看。
```

看結果：三段的連結都點得開；「時間」那一段要連到 `[[時間軸]]`（用你的實際檔名）。

4. 打開〈三國演義〉，在最後一行加 `[[知識庫導覽]]`。
5. 勾 dg-publish：導覽頁、時間軸，還有導覽頁連到的卡。
6. Ctrl／Cmd + P，執行 Publish All Notes Marked for Publish，等兩分鐘再打開網址。

看結果：從首頁點得到時間軸；時間軸上的人名和來源卡都是純文字，沒有 `[[ ]]`，也沒有點了會 404 的連結。有的話，回第三堂的 SKILL.md 補規則，再產生一次。

## 練習 4（驗收）：同學從首頁找到新卡

定位：一張新卡｜期望輸出：同學走得到｜限制：只能從首頁點

1. 公開一張新卡，例如第三堂新增的〈三英戰呂布〉，在導覽頁加上它的連結，發布。
2. 把網址傳給同學。
3. 同學只能從首頁開始點，不能直接打卡片的網址，看走不走得到這張新卡。
4. 走到了就打勾；走不到，回報卡在哪一頁。你回去查那一頁的 dg-publish 和連結，修好再發布。做完交換角色。

看結果：走不到通常是那張卡忘了勾 dg-publish，或連結的卡名打錯。

## 導覽頁練習：做導覽頁

```text
新增 整理/知識庫導覽.md：放入擴充後關係圖和故事時間線的 [[連結]]。
寫兩條路「從人物看關係」「按故事順序看」，各舉一個找得到出處的例子。
不改來源卡，不連 .txt，不加 dg-publish；寫入前先給我看差異。
```

看結果：兩條路各一個例子，點得到卡片；沒有「待確認」之類的標記。
做完自己動手：在〈三國演義〉最後一行打 `[[知識庫導覽]]`，網站首頁才走得到導覽頁。

## 完整練習：核對新卡

```text
說明〈三顧茅廬〉和〈草船借箭〉每一句出自 原文/ 哪份節選。
找不到出處的句子標出來，不要改檔案。
```

看結果：每句都對得到節選；找不到的先刪掉，再發布。

## 加分（課後）：做成一個網頁

```text
把擴充後關係圖和故事時間線做成一個 HTML 檔，同頁顯示。
不載入外部套件，每個節點連回來源筆記。
```

看結果：雙擊 HTML 打開，點節點能回到筆記。
