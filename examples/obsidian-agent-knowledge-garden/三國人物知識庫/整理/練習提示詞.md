# 練習提示詞

今天把三國卡片盒交給 Agent：查筆記、補 4 張卡、重畫圖、做導覽頁。
每段整段複製到 Codex，一次貼上再按 Enter。這頁不會發布。

## 查筆記練習

```text
依這個筆記庫，曹操參與了哪場戰役？
從〈曹操〉找起，核對相關的關係卡，回答並附檔名。
筆記沒寫的細節不要補。
```

看結果：答「赤壁之戰」，附 曹操.md、赤壁之戰.md。

## 練習一：畫現有的關係圖

```text
讀〈三國演義〉和人物、勢力、關係資料夾的 12 張卡，不改原檔。
用純文字畫「人物 → 關係卡 → 人物」，線只看每張關係卡最後的「參與人物」。
圖下方另附一份 [[連結]] 清單，每條線一行，並列出還沒有卡的人物和事件。
存成 整理/人物關係圖－擴充前.md，不加 dg-publish。
```

看結果：約 14 條線；點清單裡的連結，每張卡都打得開。

## 練習二：請 Agent 照原文補 4 張卡

```text
只根據 原文/ 三份節選，新增 人物/諸葛亮、人物/周瑜、關係/三顧茅廬、關係/草船借箭。
寫法比照舊卡；「參與人物」只列有卡的人（含這次新增的諸葛亮、周瑜）。
節選找不到根據的不寫；舊卡不改，新卡不加 dg-publish。
寫入前先給我看差異，並列出找不到出處的句子。
```

看結果：差異只有 4 個新檔；新卡附回目和節選檔名，「參與人物」裡沒有魯肅這類沒卡的人。

## 練習三：重畫圖，排時間線

```text
用練習一的規則，重畫 16 張卡的關係圖，存成 整理/人物關係圖－擴充後.md。
再依小說回目排出 整理/故事時間線.md，每件事連回它的關係卡。
兩個檔都不加 dg-publish，最後比較前後兩張圖多了什麼。
```

看結果：時間線是回目（第 1、21、37–38、46、49–50 回），不是西元年。

## 導覽頁練習：做導覽頁

```text
新增 整理/知識庫導覽.md：放入擴充後關係圖和故事時間線的 [[連結]]。
寫兩條路「從人物看關係」「按故事順序看」，各舉一個找得到出處的例子。
不改來源卡，不連 .txt，不加 dg-publish；寫入前先給我看差異。
```

看結果：兩條路各一個例子，點得到卡片；沒有「待確認」之類的標記。
做完自己動手：在〈三國演義〉最後一行打 `[[知識庫導覽]]`，網站首頁才走得到導覽頁。

## 完整練習：核對新卡

```text
說明〈三顧茅廬〉和〈草船借箭〉每一句出自 原文/ 哪份節選。
找不到出處的句子標出來，不要改檔案。
```

看結果：每句都對得到節選；找不到的先刪掉，再發布。

## 加分（課後）：做成一個網頁

```text
把擴充後關係圖和故事時間線做成一個 HTML 檔，同頁顯示。
不載入外部套件，每個節點連回來源筆記。
```

看結果：雙擊 HTML 打開，點節點能回到筆記。
