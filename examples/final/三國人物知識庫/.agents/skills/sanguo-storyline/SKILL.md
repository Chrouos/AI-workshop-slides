# 人物故事線

## 步驟
1. 讀 人物/主角.md，和 關係/ 裡「參與人物」有主角的每張卡
2. 每一站寫出：回目、事件名稱、當時同場的人，以及他們在「這一站」和主角的關係
3. 對照 原文/ 確認回目和在場的人；原文找不到的人不放
4. 依回目由小到大排；同一回有兩件事，照原文先後
5. 寫入 整理/主角的故事線.md，開頭加 dg-publish: true

## 關係只用六種
- 放左邊（同伴）：兄弟 #b0533c、投靠 #947346、盟友 #4e7d5b、謀士 #7b5a8c
- 放右邊：對手 #4a6587
- 寫在事件框裡「同場：…」：其他 #8c8273（說不上敵友的人）
- 同一個人在不同站可以換邊，例如曹操先是盟友，後來變成對手

## 輸出格式
- 一段 HTML，每一站一列，三欄：同伴 ── 事件 ── 對手
- 事件框放中間，寫回目和事件名稱；各站的事件框上下用一條直線串起來
- 左欄靠右排、右欄靠左排，兩邊用虛線連到事件框；哪一邊沒有人，那邊就不畫虛線
- 每個名字旁邊寫關係，左邊的色條用關係的顏色，上方附圖例
- 太窄時可以左右捲動，不要擠壓名字
- 只用 inline style，不用 <script>、<style>；HTML 裡的名字用純文字，不加 [[ ]]，也不做連結
- HTML 中間不要有空白行
- HTML 下面寫「一站一站看」：每站一兩句，用 [[連結]] 連到事件卡和人物卡
- 再加一張「他遇到的人」表格：人物｜第一次同場（回目）｜和主角的關係｜卡片
- 最後一行寫出處：用到的 原文/ 檔名
