# AI 協作工作坊課綱：用 AI 建一座三國知識庫

四堂課，每堂 2 小時（含練習），共 8 小時。

整個課程只做一件作品：一座《三國演義》知識庫。第一堂用 Codex 寫出大綱，第二堂放進 Obsidian 和人物卡連起來，第三堂用 Skill 擴充、畫圖、排時間軸，第四堂發布成網站。每堂課都接著上一堂的成果做。

三條主線貫穿四堂課：

| 主線 | 第一堂 | 第二堂 | 第三堂 | 第四堂 |
| --- | --- | --- | --- | --- |
| RAG | 概念：Web Search 就是 RAG | 實作：在自己的筆記庫查資料、附出處 | 應用：時間軸只照卡片排，沒寫的不補 | 成果：網站上每張卡都有出處 |
| Obsidian | （預告） | 安裝、連結、關係圖 | 用回目排時間軸 | Digital Garden 發布 |
| Skills | （預告：AGENTS.md） | （預告） | 安裝、使用、自己寫一個 | 把 Skill 產出放上網站 |

### 10–39　AI 怎麼走到今天

用一條因果鏈講，每一步都是上一步的問題催生出來的：

1. **預測下一個字（2022，GPT-3.5）**：看前文，從機率表挑下一個字，一直接下去。
2. **隨機性**：每次不一定挑機率最高的那個字，所以同一題問兩次，答案會不一樣。現場示範：同一題按兩次「重新產生」。
3. **幻覺**：它挑的是「最常見的說法」，不是「查證過的說法」，所以會很肯定地講出沒有根據的內容。例子：早期 GPT-3.5 把一長串加法算成 8402（正解 8484）。
4. **解法一：Thinking（CoT，思考鏈）**：先把問題拆成步驟，一步一步算，最後再驗算。這比較少推理錯誤，但本質上還是在「心算」，靠模型自己記得的東西。
5. **解法二：使用工具（像按計算機）**：遇到算術，模型在背後寫一行程式來算，就像把數字輸入計算機、按下等於。這樣得到的是真的算出來的結果，每次都一樣，不再是隨機猜的。實測：請 Codex「用程式算出來」，它執行 `python3 -c 'print(sum([...]))'`，得到 8484。
6. **解法三：Web Search ＝ RAG**：搜尋也是一種工具。計算機幫它算，搜尋幫它查：先查資料，再回答。RAG 分三步：
   - R 檢索：找資料。
   - A 增強：把資料和問題一起交給 AI。
   - G 生成：照資料回答，並附上來源。
   比喻：開書考。
7. **再下一步：Agent**：會自己用工具、執行任務，Codex 就是一個 Agent。

### 練習 1：和 ChatGPT 聊天（課後自己練，約 15 分鐘）

同一個問題問三次，看「給不給資料」差在哪：
- 1-1（幻覺）：先不給資料，問「劉備聽完曹操說『天下英雄只有你我』，做了什麼？為什麼？」它會憑記憶答出掉筷子、怕被看穿。
- 1-2（查證）：追問「你說的原因，原文哪一句寫的？引用原句，附維基文庫連結」，點開連結後按 Cmd/Ctrl+F 搜「掩飾」，搜得到同一句才算數。
- 1-3（RAG）：開新對話，附上第 21 回的一段節錄再問同一題。節錄只寫他吃了一驚、筷子掉了，沒寫原因；看它有沒有照原文說「原文沒寫」，還是又補了原因。補了就追問「原文哪一句？」。
- 提示詞和原文都放在練習資料夾的 `prompts.md`（GitHub 上可直接開），不用照投影片打字。
- 參考結果在練習資料夾的 `ChatGPT_練習/`，做完可以對照。

### 67–91　看懂 Codex

- 啟動畫面：model、directory 兩個欄位；model 後面的 high 是思考程度。（登入、信任資料夾在第三章已做完。）
- **`/status`（練習 2-1）**：學生自己打 `/status`，Directory 結尾是 `Codex_練習` 才對；結尾是 `aw-01-lab` 就 `/quit`、`cd Codex_練習`、再開 `codex`。確認後 Codex 開著不關，第五章直接用。
- **Usage 和 Token**（簡單帶過）：Usage 是帳號額度，Token 是處理文字的單位。
- **模型大小**：參數量，1B 是 10 億個參數；同一系列通常越大越強，也越吃記憶體。24 GB 顯示卡（RTX 4090）大約跑到 30B 左右的量化版，幾百 B 的模型要在雲端跑。
- **Reasoning Effort**：low／medium／high／xhigh。調高會多花 Token 和時間，答案不一定比較好（GPT-5 實測：high 的 Token 是 minimal 的 23 倍，medium 到 high 只多 1 分；劉備那題 low 和 xhigh 都答對）。
- **推理成本**：單價 × Token 數。Kimi K2 Thinking 單價是 GPT-5（high）的四分之一，但 Token 用了約 2 倍，總花費只便宜 2.5 倍。
- **Session**：一次工作的工作桌，前面講過的它都看得到；`/new` 會換一張空桌子。
- **Memory**：分兩層。聊天裡說的，換了 Session 就忘；寫進 `AGENTS.md` 的，每次開 Session 都會讀。

### 91–116　練習 2：用 Codex 寫大綱

1. 先看講師示範影片（OpenCode，約 5 分鐘，從 `cd` 到大綱存檔），再自己做。2-1 已在「看懂 Codex」做完，Codex 還開在 `Codex_練習`。
2. 練習 2-2：用文字編輯／記事本自己建 `AGENTS.md`，存進 `Codex_練習`，三行規則：「回答問題時，只根據 原文/ 資料夾裡的文字；找不到就說『原文/ 裡找不到』；每次回答的最後一行寫『出處：原文/第00N回.md』。」回到開著的 Codex 打 `/new`，問「劉備第一次出場在第幾回？」，最後一行有這個格式才算生效；再問「諸葛亮第一次出場在第幾回？」，有規則會說找不到，沒有規則會答第 37 回。沒照規則就 `/quit`、再打 `codex` 重問，還不行就檢查檔名。
3. 練習 2-3：請 Codex 根據資料夾裡的回目原文，寫出第 1–21 回的大綱：人名寫成 `[[人名]]`，每段標回目，存檔前先給你看，存成 `三國演義大綱.md`。跑不出來就先改成「第 1 回到第 2 回」。
4. 練習 2-4 核對：請 Codex「三國演義大綱.md 第 N 回那段的第二句，根據原文哪一句？引用原句。」，再用文字編輯／記事本打開那一回，Cmd/Ctrl+F 搜那句，搜不到就回 Codex 請它重新確認；標題和 `回目.md` 對一對。這一步就是第一次在自己的資料上做 RAG。

**課前準備**：安裝 Codex（獨立安裝，不需 Node.js）、確認 ChatGPT 方案能用 Codex；講師準備練習資料夾（含回目原文）。

### 11–27　什麼是 Skill

- 開場先看成果：一句提示詞，Codex 照 eli5 改寫劉備卡（講師事先跑好的結果，不現場跑），再回頭講 Skill 是什麼。
- 練習 1、2、3 各有一段講師錄影（`slides/aw-03/assets/`），課堂上不現場跑；錄影放在該練習開始前當示範：先看講師做一次，再自己做。
- Skill 是交給 Agent 的一份 SOP：某一類工作要怎麼做、做完長什麼樣子。
- 打開一份 `SKILL.md` 看結構：`name`、`description`（決定什麼時候會被叫出來）、步驟、輸出格式。
- 四種東西的比較：

| | 是什麼 | 什麼時候用 |
| --- | --- | --- |
| Prompt | 這一次的要求 | 只做一次的事 |
| AGENTS.md | 這個專案的規則 | 每次都要遵守的事 |
| Skill | 某一類工作的做法 | 常常重複做的事 |
| MCP | 連到外部工具或資料 | 要查外部系統的時候 |

- 主線只教「在提示詞寫出 Skill 名稱」來使用；description 自動挑選、載入原理、MCP 圖解和 Skill／MCP 判斷題放附錄。

### 27–44　練習 1：安裝熱門 Skill

- 先看懂指令：`npx skills add 帳號/專案`。`npx` 是 Node.js 附的工具；`skills add` 是 Vercel Labs 的 Skill 安裝程式；最後一段取自 GitHub 網址 `github.com/` 後面兩段。
- 先確認工具，先 git 再 Node.js：`git --version`（skills 用 git 從 GitHub 下載）、`node -v`（要 v22.20 以上）、`npx -v`。git 照官網 git-scm.com/install：Mac 先裝 Homebrew（brew.sh）再 `brew install git`（`xcode-select --install` 常因軟體更新伺服器取不到而失敗）；Windows 到 git-scm.com/install/windows 按 Click here to download。Node.js 到 nodejs.org 裝 LTS。投影片上的網址都做成可點的連結。
- 先 `cd` 進筆記庫，再安裝，兩個都選 **Project**（裝進筆記庫的 `.agents/skills/`，和 sanguo-timeline 同一個地方）：
  ```bash
  npx skills add dreambigou/eli5
  npx skills add cathrynlavery/diagram-design
  ```
  互動選單：`Ok to proceed? (y)` 按 Enter → Agent 清單裡 Codex 在 Universal（always included），不用勾，直接 Enter（用 Claude Code 的人空白鍵勾 Claude Code）→ Installation scope 選 Project → Symlink → Yes。
- 常見錯誤：`command not found: npx`（沒裝 Node.js）、`spawn git ENOENT`（沒有 git）、Windows「已停用指令碼執行」（改打 `npx.cmd`）。
- 都不行：GitHub 按 Code → Download ZIP，把「裡面直接有 SKILL.md」的那層資料夾拖進筆記庫的 `.agents/skills/`（Claude Code 是 `.claude/skills/`）。
- 開新 Session，確認 Codex 看得到這兩個 Skill。

- 進階：在 SKILL.md 加第 4 步，指定人物時畫成他的故事線（只留有劉備的事件，左邊同一邊、中間事件、右邊作對）；換一個畫圖 Skill（diagram-design、archify，或用 `npx skills find` 找）畫同一條時間軸。

## 實測結果（2026-10-17，講師電腦，Codex 0.154.0）

1. **第一堂的大綱資料**：已經準備好 `examples/aw-01-lab/`，也打包成 `examples/aw-01-lab.zip`（投影片 QR 指向 GitHub raw 連結，要 push 到 main 才能下載）。裡面分成 `ChatGPT_練習/`（練習 1 參考結果）、`Codex_練習/`（維基文庫第 1–21 回的全文 `原文/第001回.md`…`第021回.md`（2026-10-30 從 .txt 改成 .md，讓第二堂放進 Obsidian 看得到） 和 `回目.md`，Codex 在這裡打開）和 `prompts.md`。用練習 2-3 的提示詞實跑：1 分 38 秒寫完 21 段，每段都附出處。有一個小毛病：它把回目標題裡的人名也加上了 `[[ ]]`。提示詞要補一句「標題裡的人名不用加連結」。
2. **HTML 能不能上 Digital Garden**：用講師網站的模板在本機建置測試。
   - 筆記裡直接寫 HTML、`<style>`、`<script>`，都能正常顯示、執行。

3. **沒有 Codex 方案的學生**（2026-10-17 實測），建議的順序：
   - **第一順位：opencode＋免費雲端模型**。不用登入，也不用信用卡。
     1. 用 `npm install -g opencode-ai` 安裝（opencode 1.19.3；2026-10-30 起投影片改用官網的 `curl -fsSL https://opencode.ai/v2/install | bash`，不需 Node.js）。

     - 速率限制官方沒寫，超過會回 429。全班用同一個 IP 可能被限流，免費模型清單也會變。
     - 不要放個資。Big Pickle 等模型可能拿資料訓練。
   - **第二順位：Codex＋OpenRouter**：
     1. 註冊 OpenRouter，拿 API key。
     2. 在 config 寫 `[model_providers.openrouter]`，`wire_api = "responses"`。
